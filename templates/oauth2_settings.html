How to register an Azure app (5 min, one-time per app)

  1. Go to Microsoft Entra ID → App Registrations
  2. Click New Registration
  3. Name: Mail Archiver (or "Family Mail Archiver", etc.)
  4. Supported account types: Accounts in any organizational directory and personal Microsoft accounts (required for personal @hotmail.com / @outlook.com)
  5. Redirect URI: Web → {{ request.url_root }}oauth2/callback
  6. Click Register
  7. Copy the Application (client) ID — paste in the app's "Client ID" field here
  8. Go to Certificates & secrets → New client secret. Set expiration to 24 months
  9. Copy the secret Value (not the Secret ID — common gotcha) — paste in the app's "Client Secret" field here
  10. Go to API permissions → Add a permission → APIs my organization uses → search Office 365 Exchange Online → Delegated → IMAP.AccessAsUser.All. Personal MSAs: consent happens at first sign-in.

Tenant field: use common for the standard "any org + personal MSA" registration. Use a specific tenant GUID or verified domain (e.g. yourco.onmicrosoft.com) only for single-tenant apps.
