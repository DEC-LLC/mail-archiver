Microsoft OAuth2 Settings

To use Microsoft (Outlook/Hotmail) accounts with OAuth2, you need to register a free Microsoft Entra ID app (formerly “Azure AD” — renamed 2023, same portal). This gives you a Client ID and Client Secret that Mail Archiver uses to authenticate with Microsoft on your behalf.

Setup takes about 5 minutes. You only do this once.
  1. Go to Microsoft Entra ID → App Registrations
  2. Click New Registration
  3. Name: Mail Archiver
  4. Supported account types: Accounts in any organizational directory and personal Microsoft accounts (required for personal @hotmail.com / @outlook.com accounts)
  5. Redirect URI: Web → {{ request.url_root }}oauth2/callback
  6. Click Register
  7. Copy the Application (client) ID — paste below
  8. Go to Certificates & secrets → New client secret. Set expiration to 24 months — Azure defaults to 180 days; if you accept that default your OAuth silently breaks in ~6 months.
  9. Copy the secret Value (not the Secret ID — common gotcha) — paste below
  10. Go to API permissions → Add a permission → APIs my organization uses → search Office 365 Exchange Online → Delegated → IMAP.AccessAsUser.All. Tenant accounts: click Grant admin consent after adding the permission. Personal @hotmail.com / @outlook.com accounts: skip that button — consent happens at first sign-in.

Heads-up: if your Mail Archiver deployment uses a self-signed HTTPS cert, your browser will warn once at the OAuth callback step. Accept the exception and the callback completes normally.
